Ορισμένες ενέργειες των γονέων μπορεί να αναστατώσουν τα παιδιά σε σημείο που να μην συνεργάζονται. Εάν τέτοιες συμπεριφορές αποφεύγονται από τους γονείς, μπορούν να βεβαιωθούν ότι δεν  ευθύνονται οι ίδιοι για τα ξεσπάσματα των παιδιών τους αλλά κάποιος εξωγενής παράγοντας. 

 Μερικές φορές οι συναισθηματικές τους εκρήξεις των παιδιών είναι τόσο δύσκολο να τις διαχειριστούν οι γονείς που τους κάνουν να  νιώθουν αβοήθητοι και σε απόγνωση όταν τα παιδιά τους συμπεριφέρονται με αυτόν τον τρόπο. 
Δεν μπορείτε απλά να αγνοήσετε μια τέτοια συμπεριφορά των παιδιών σας και οποιαδήποτε λανθασμένη ενέργεια από την πλευρά σας μπορεί μόνο να επιδεινώσει περαιτέρω τα πράγματα. 

**Αποτυχία να αναγνωρίσουν τα επιτεύγματά τους**
Πρέπει να ενθαρρύνετε τα παιδιά σας και να τα επιβραβεύετε καλά ακόμα και για τα μικρότερα επιτεύγματά τους. Τα παιδιά χρειάζονται πολλά κίνητρα με τη μορφή ενθάρρυνσης από καιρό σε καιρό. Εάν τα μικρά επιτεύγματα ή η σκληρή δουλειά τους περάσουν απαρατήρητα, δεν έχουν αρκετά κίνητρα για να εκτελέσουν ξανά αυτό το έργο.

![](/img/μητέρα.jpg "παρατήρηση")

**Χρήση πολλών αρνητικών λέξεων**
Τα παιδιά μπορεί να αποθαρρύνονται εύκολα εάν τα περιβάλλει πολλή αρνητικότητα. Αποφύγετε να χρησιμοποιείτε εκφράσεις όπως «άτακτος/η», «Μην μιλάς, Μην φωνάζεις Μην…», «Τι έκανες πάλι;», «Αν ξανα-…. Θα σε …..» Αποφύγετε τις απειλές ιδίως αυτές που δεν θα εκτελέσετε. 
 Ένα αρνητικό περιβάλλον μπορεί να έχει μια πολύ μόνιμη εντύπωση στο μυαλό των παιδιών, κάτι που δεν είναι καλό για αυτά. Τους πονάει να ακούν τέτοια λόγια από τους γονείς ή τους δασκάλους τους, που υποτίθεται ότι τους αγαπούν τόσο πολύ. Χρησιμοποιήστε εκφράσεις όπως: «Αυτό που κάνεις δεν σε βοηθά……». «Τι σου συμβαίνει σήμερα και είσαι αναστατωμένος/η» « Θέλω να μιλήσουμε για αυτό που κάνεις τώρα….». 
**Όταν απειλείται**
Τα παιδιά είναι πολύ μικρά για να χειριστούν τις απειλές. Οι δάσκαλοι ή ακόμη και οι γονείς μερικές φορές απειλούν τα παιδιά να τα αναγκάσουν να κάνουν μια συγκεκριμένη εργασία. Η απειλή είναι ένα είδος συναισθηματικής κακοποίησης. Σε κανέναν δεν αρέσει να απειλείται. Όταν απειλείτε, το παιδί σας θα προσπαθήσει να αμυνθεί αναστατώνοντας. Η κατάσταση μπορεί να επιδεινωθεί περισσότερο.

**Προσπαθώντας να επιβάλετε τις ιδέες σας**
Οι αναγκαστικές σας ιδέες στα παιδιά θα μπορούσαν να τα αναστατώσουν. Τα παιδιά έχουν το δικό τους μυαλό. Στην πραγματικότητα τα παιδιά είναι πιο δημιουργικά από τους ενήλικες. Δώστε τους την ελευθερία να εξερευνήσουν πλήρως το δημιουργικό τους μυαλό. Μην τους ελέγχετε και προσπαθήστε να τους επηρεάσετε ή να τους επιβάλλετε τις ιδέες σας. Τέτοιες ενέργειες εκ μέρους σας θα αναστατώσουν το παιδί σας.

**Όταν ελέγχεται χωρίς εξηγήσεις**
Οι δάσκαλοι ή οι γονείς μπορούν να καθοδηγήσουν τα παιδιά αλλά δεν πρέπει να προσπαθούν να τα ελέγξουν καταπιέζοντας τα. Όταν ελέγχετε το παιδί σας, να είστε προετοιμασμένοι για μια αρνητική αντίδραση. Όταν θέλετε να βάλετε ένα όριο στην συμπεριφορά του παιδιού προσπαθήστε να πείσετε το παιδί με επιχειρήματα και περιμένετε να τα σκεφτεί και να τα αποδεχτεί.

**&#32;Όταν Αγνοείται**
Δώστε προσοχή στο παιδί σας καθημερινά. Όταν δεν μιλάτε, δεν παίζεται, δεν το ακούτε το παιδί σας, αισθάνεται ανεπιθύμητο και ασήμαντο. Δεν πιστεύει στον εαυτό του και κάνει αταξίες για να πάρει ακόμη και την αρνητική σας σημασία. Αν αγνοήσετε το παιδί, θα το  αναστατώσετε περισσότερο το παιδί με αποτέλεσμα να μην συνεργάζεται μαζί σας και το σχολείο, να προκαλεί προβλήματα ή να πέσει σε κατάθλιψη.

**Όταν τιμωρείται**
Η τιμωρία δεν πρόκειται να βοηθήσει. Το παιδί σας δεν θα μάθει τα λάθη του μέσω της τιμωρίας. Αντίθετα, τα παιδιά αισθάνονται άσχημα και ταπεινωμένα.

**Όταν γίνεται κριτική**
Επικοινωνήστε με το παιδί σας χωρίς να είστε επικριτικοί. Πες του όταν κάνει λάθος. Μην κατακρίνετε το παιδί αλλά την πράξη του. Εξηγήστε στο παιδί τις συνέπειες της πράξης του.  Η κριτική όχι μόνο κάνει τα παιδιά να αισθάνονται άχρηστα, αλλά μπορεί επίσης να τα φέρει σε αμηχανία και να τα αναστατώσει πολύ άσχημα. Είναι αναμενόμενο να κάνει λάθος για να μάθει κιόλας.

**Σε σύγκριση με άλλους**
  Κάθε παιδί είναι μοναδικό και      διαφορετικό. Μην συγκρίνετε το παιδί σας με άλλα παιδιά. Αναστατώνονται εύκολα.

**Οικογενειακά προβλήματα**
Πολλά προβλήματα στην οικογένεια, όπως ένταση ή διαζύγιο μεταξύ των γονιών, θάνατος στην οικογένεια, κακή οικονομική κατάσταση, ψυχολογικά προβλήματα κ.λπ. μπορεί να αναστατώσουν τα παιδιά και να οδηγήσουν σε συμπτώματα στέρησης αγάπης και σημασίας.
Απαιτείται πολύ προσεκτικός χειρισμός της κατάστασης. Δεν είναι σκόπιμο να κάνετε συλλογισμούς με ένα ήδη αναστατωμένο παιδί. Τα παιδιά δεν θέλουν μεγάλες εξηγήσεις. Τα παιδιά δεν μπορούν να ελέγξουν τα συναισθήματά τους Τα παιδιά χρειάζονται την υποστήριξή σας για να χειριστούν τα συναισθήματά τους. Είναι αρκετά ευαίσθητοι και κάθε λάθος χειρονομία ή λεκτική επίθεση από την πλευρά σας ως γονέα μπορεί να προκαλέσει θυμό στο παιδί σας.
